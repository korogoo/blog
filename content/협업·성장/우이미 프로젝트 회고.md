내 기억력이 안 좋아서 노션 기록을 긁어 정리해둔다

우이미 = "우리들은 이별을 미루기로 했다"

친환경 활동이 놀이가 되는 커플 앱

<br/>

---

### 한 줄 정리

친환경 실천을 커플앱 게임화 공식(즉각 보상 + 감정 연결)에 얹은 앱

볼런톤(봉사 해커톤)에서 시작 -> 3개월 진행 -> 경기도지사상 수상

<br/>

## 어떤 팀이었나

- 아리백 + 그린리틀 두 팀이 볼런톤에서 만나 시작 -> 이후 2명 합류
- 팀명 아리그린
- 주최/멘토 : 경기자원봉사센터, 쏘셜공작소
- GitHub org : ReGreenOrg
- 베타 : wooimi.com / 배포 : r2green.duckdns.org

<br/>

---

### 내가 한 것 (서버 전부 혼자)

✨ **서버는 나 혼자 담당했다**

NestJS를 처음 써봤는데 7일 동안 공식문서 + 강의로 학습해서 구현

<br/>

## 구현한 것

- 소셜로그인 -> JWT(Bearer) 인증
- 표준 응답 포맷 : `code` / `message` / `data`
    - 21xx 성공, 4xxx 클라 오류, 5xxx 서버 오류
- 도메인별 ErrorCode 체계
    - auth 41xxx / couple 42xxx / coupleItem 43xxx / ecoVerification 44xxx / item 45xxx / member 46xxx
- 도메인 7개 : auth, couple, coupleItem, ecoVerification, item, member, memberEcoVerification
- FCM + Firebase Admin SDK 위치기반 푸시 -> AR 미션 진입 (Geofencing)
- DuckDNS 배포

<br/>

## 포폴 소재 후보 ✨

포인트 정합성 검증 SQL을 짰던 기록이 있다

> 커플 잔여포인트 + 구매총액 == 활동포인트합 + 50
> 이 식이 안 맞는 커플을 찾아내는 쿼리

-> "데이터 정합성을 고민한 백엔드 경험"으로 풀 수 있는 진짜 소재

<br/>

---

### 솔직한 약점

⚠️ **AI에 많이 의존해서 구현했다**

지금 "이 코드 왜 이렇게 했냐" 물으면 제대로 설명 못 한다

2026 면접 트렌드(바이브 코딩 -> 면접관이 깊이를 더 봄)와 정면 충돌하는 지점

<br/>

✨ **그런데 이게 기회다**

재학습하는 과정 자체가 블로그 소재가 되고

내 포지셔닝("왜?를 파서 자기 기준 세우는 개발자")의 증거가 된다

❓ 어떤 기능부터 재이해할까 -> 정합성 SQL or JWT 인증부터

<br/>

---

### 소프트스킬 경험 (포폴 근거)

"같이 일하고 싶은 개발자" 포지셔닝의 재료

- 콜드메일 보내는 법을 멘토에게 배워서 실제로 협찬 따냄 (미놉, 동구밭, 제리백)
- 사람 설득하는 법, 좋은 기획서란 무엇인가를 배움
- 부스 2회 직접 운영 -> 현장에서 92명 사용자 모객
- 미놉 대표를 부스에서 직접 만나 협찬 연결

<br/>

### 남은 작업

❓ 내가 맡은 기능 중 면접에서 설명 가능한 수준까지 끌어올릴 1~2개 선정
❓ 그 과정을 블로그(트러블슈팅/기준 세우기)로 기록
❓ 포폴에는 정합성 SQL + 혼자 7일 학습 스토리를 축으로
