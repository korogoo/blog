낙관적 락이 단일 서버에서 동작한다는 건 알겠는데,

서버가 여러 대면 락도 서버마다 따로 생기는 게 아닐까 싶었다

---

## 락은 어디서 거는 걸까?

> ==락이 걸리는 위치는 DB에 있다==

```
서버 A ────┐
          ▼
서버 B ──► 단일 DB (락 매니저가 여기 있음)
```

서버가 몇 대든 모두 같은 DB 락 매니저에 요청한다

서버 대수는 변수가 아니다

---

## 그럼 언제 다중 서버가 문제가 되나?

락이 DB 바깥에 있을 때다

```java
synchronized (this) { ... }  // JVM 내 락
```

`synchronized`는 JVM 안에서만 유효하다

서버가 두 대면 각자 자기 JVM에서 락을 잡으므로 서로를 막지 못한다

이 경우엔 Redis 같은 분산 락이 필요하다

---

## 정리

| 락의 위치                  | 다중 서버에서 유효한가? |
| ---------------------- | ------------- |
| DB 락 (비관적 / 낙관적)       | O             |
| JVM 락 (`synchronized`) | X             |
| Redis 분산 락             | O             |
