낙관적 락으로 INSERT 중복도 막을 수 있지 않을까 싶었다

`@Version`을 엔티티에 달면 되는 거 아닌가?

---

## 낙관적 락의 원리

✨ **`@Version`은 UPDATE 시점에 충돌을 감지한다**

```sql
UPDATE reservation
SET version = 1
WHERE id = ? AND version = 0
```

> 내가 읽은 그 행이 그대로인지 ==원자적으로 확인==하는 것이다

version이 바뀌어 있으면 누군가 먼저 수정한 것이므로 충돌로 처리한다

---

## INSERT에 적용하면?

INSERT는 비교할 기존 행 자체가 없다

```
서버 A: INSERT → id=100, version=0 생성
서버 B: INSERT → id=101, version=0 생성  ← ⚠️ 다른 행이라 충돌 없음
```

두 서버가 각자 새 행을 만들었기 때문에 version 체크가 일어나지 않는다

---

## 정리

> `@Version`은 ==UPDATE 충돌 감지용==이다  
> 
> INSERT 중복 방지는 Unique 제약이 최후의 방어 방법이다
