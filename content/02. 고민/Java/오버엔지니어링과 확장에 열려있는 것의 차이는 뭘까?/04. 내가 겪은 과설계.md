## 사례: SangSetup 계층

장기 미션 사이클1에서 상차림(기물 초기 배치)을 구현할 때 이런 구조를 만들었다

```
SangSetup (인터페이스)
    └── GeneralSangSetup (추상 클래스)
            ├── LeftMaSangSetup
            ├── RightMaSangSetup
            ├── LeftSangMaSetup
            └── RightSangMaSetup
```

마와 상의 생성 **순서 차이 하나**를 표현하기 위해 클래스 6개를 만들었다

## 받은 피드백
