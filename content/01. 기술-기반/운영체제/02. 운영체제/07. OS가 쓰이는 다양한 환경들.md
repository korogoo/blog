## OS는 어디에나 있다

운영체제라고 하면 Windows나 macOS를 떠올리기 쉽다

하지만 OS는 훨씬 넓은 세계에 존재한다

<br/>

- [?] **다음 중 OS가 필요 없는 것은?**

- [>] 휴대폰 → iOS, Android
- [>] 텔레비전 → 스마트 TV OS
- [>] 자동차 → ECU, 자율주행 OS
- [>] **지갑** → (일반 지갑은 No. 하지만 스마트 지갑이라면?)

> 정보를 처리하는 기계라면, OS가 필요하다.

---

## 1. 전통적 컴퓨팅 (Traditional Computing)

우리가 알던 그 컴퓨터

- [>] 데스크탑, 노트북
- [>] Windows, macOS, Linux
- [>] 한 명의 사용자가 직접 사용

---

## 2. 모바일 컴퓨팅 (Mobile Computing)

스마트폰과 태블릿의 등장으로 OS의 요구사항이 바뀌었다

- [>] 배터리 효율이 중요
- [>] 터치 인터페이스
- [>] 항상 연결 (네트워크)
- [>] 대표 OS: **iOS, Android**

---

## 3. 클라이언트-서버 컴퓨팅 (Client-Server Computing)

```
┌──────────────┐         ┌──────────────┐
│   Client     │ ──────► │   Server     │
│  (브라우저)   │ 요청     │  (웹서버)     │
│              │ ◄────── │              │
└──────────────┘  응답    └──────────────┘
```

- [>] 클라이언트가 요청 → 서버가 처리 → 응답 반환
- [>] 백엔드 개발의 기본 구조
- [>] 서버 측 OS는 대부분 **Linux** 기반

---

## 4. P2P 컴퓨팅 (Peer-to-Peer Computing)

```
[A] ←──→ [B]
 ↕        ↕
[C] ←──→ [D]
```

- [>] 중앙 서버 없이 참여자들이 직접 연결
- [>] 각 노드가 클라이언트이자 서버
- [>] 예: 토렌트, 블록체인

---

## 5. 클라우드 컴퓨팅 (Cloud Computing)

- [I] **인터넷 너머 어딘가의 컴퓨터를 빌려 쓴다**

```
사용자
  │
인터넷
  │
┌─────────────────────────────────┐
│         Cloud Provider          │
│  ┌──────┐ ┌──────┐ ┌──────┐   │
│  │ VM 1 │ │ VM 2 │ │ VM 3 │   │  ← 가상화로 분리
│  └──────┘ └──────┘ └──────┘   │
│        물리 서버 수천 대        │
└─────────────────────────────────┘
```

<br/>

클라우드 서비스의 세 단계

|종류|제공하는 것|예시|
|---|---|---|
|**IaaS**|인프라 (서버, 네트워크)|AWS EC2, GCP Compute|
|**PaaS**|플랫폼 (OS + 런타임)|Heroku, App Engine|
|**SaaS**|소프트웨어 자체|Gmail, Notion, Figma|

가상화가 클라우드의 핵심 기술이다

AWS 서버 하나를 빌리면, 사실 누군가의 물리 서버 위에서 VM이 돌아가는 것이다

---

## 6. 실시간 임베디드 시스템 (Real-Time Embedded Systems)

특정 기능만을 위한 컴퓨터들

```
자동차 에어백: 충돌 감지 → X ms 이내에 반드시 작동
```

- [>] **실시간(Real-Time)**: 정해진 시간 안에 반드시 응답해야 함
- [>] 지연이 곧 사고로 이어질 수 있음
- [>] 예: 자동차 ECU, 의료기기, 공장 자동화, 드론
- [>] 대표 OS: **RTOS (Real-Time OS)**

<br/>

- [?] **일반 OS(Windows, Linux)와 다른 이유**

일반 OS는 평균 성능이 목표, RTOS는 **최악의 경우에도 정해진 시간 내 응답**이 목표
