> 헤드를 어떤 순서로 이동시키느냐가 성능을 결정한다

---

## 공통 예시

```
요청 큐 (실린더 번호): 98, 183, 37, 122, 14, 124, 65, 67
현재 헤드 위치: 53
디스크 실린더 범위: 0 ~ 199
```

---

## 1. FIFO (= FCFS) 스케줄링

- [I] **FIFO: 요청이 들어온 순서대로 처리 — 공정하지만 비효율적**

```
이동 순서: 53 → 98 → 183 → 37 → 122 → 14 → 124 → 65 → 67

  0   14  37  53  65 67     98   122 124      183        199
  |    |   |   |   | |       |    |   |        |
  |    |   |   ●───────────────────────────────●  53→183 (여러 구간)
  |    |   ●───────────────────────────────────●  반복
  |    |   (헤드가 앞뒤로 크게 오감)

이동 합계:
  53→98   = 45
  98→183  = 85
  183→37  = 146
  37→122  = 85
  122→14  = 108
  14→124  = 110
  124→65  = 59
  65→67   = 2
  ─────────────
  합계     = 640
```

- [!] **총 이동: 640 실린더 — 순서가 제각각이라 헤드가 앞뒤로 많이 움직인다**

---

## 2. SCAN 스케줄링

- [I] **SCAN: 헤드가 한쪽 끝까지 이동하며 요청 처리, 끝에 닿으면 방향 반전 — 엘리베이터 알고리즘**

```
헤드 이동 방향: 0 방향 (감소)

이동 순서: 53 → 37 → 14 → 0 → 65 → 67 → 98 → 122 → 124 → 183

  0   14  37  53       65 67     98   122 124      183
  |    |   |   |        | |       |    |   |        |
  ←───────────●  (0까지 이동하며 37, 14 처리)
  ●────────────────────────────────────────────────►
  (방향 반전 후 오른쪽으로 이동하며 나머지 처리)

이동 합계: 53→0 = 53, 0→183 = 183  →  합계 236
```

- [!] **총 이동: 236 실린더**
- [i] **0에 먼저 도달 후 반전하므로, 가는 길에 있는 요청을 효율적으로 처리**

---

## 3. C-SCAN (Circular-SCAN) 스케줄링

- [I] **C-SCAN: 한 방향으로만 이동하며 처리, 끝에 닿으면 반대쪽 끝으로 즉시 점프 후 다시 같은 방향으로 진행**

```
이동 순서: 53 → 65 → 67 → 98 → 122 → 124 → 183 → 199 → [점프] → 0 → 14 → 37

  0   14  37  53   65 67     98   122 124      183  199
  |    |   |   |    | |       |    |   |        |    |
  |    |   |   ●────────────────────────────────────►  오른쪽으로 이동하며 처리
  |    |   |                                           199 도달
  ●────────►  점프 후 처음부터 나머지 처리 (199→0 구간은 처리 없음)

이동 합계: 53→199 = 146, 0→37 = 37  →  합계 183
```

- [!] **총 이동: 183 실린더 (199→0 점프 구간 제외)**
- ["] **대기 시간이 더 균등하다 — 디스크 양쪽 끝의 요청이 불이익을 덜 받는다**

---

## 알고리즘 비교

| 알고리즘 | 총 이동 | 특징 |
|---|:---:|---|
| **FIFO** | 640 | 공정, 비효율 |
| **SCAN** | 236 | 효율적, 양방향, Belady 없음 |
| **C-SCAN** | 183 | 균등 대기, 단방향 |

- [i] **현대 SSD(NVM)는 seek time이 없어 단순 FIFO를 주로 사용한다**
