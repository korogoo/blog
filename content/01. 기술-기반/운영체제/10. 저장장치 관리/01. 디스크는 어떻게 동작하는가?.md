## 보조 저장장치 (Mass Storage)

- ✨ **Mass Storage: 컴퓨터의 비휘발성(non-volatile) 보조 저장 시스템**

| 종류 | 예시 |
|---|---|
| **HDD** | 전통적인 하드 디스크 드라이브 |
| **NVM** | SSD, NVMe 등 비휘발성 메모리 |
| 기타 | 자기 테이프, 광학 디스크, 클라우드 스토리지 |

---

## HDD 구조

```
          스핀들 (Spindle)
             │
   ┌─────────┼─────────┐
   │  플래터  │  플래터  │  ← 자성 물질로 코팅된 원형 디스크
   └─────────┼─────────┘
             │
         ┌───┴───┐
         │  암   │  ← 디스크 암 (Disk Arm)
         └───┬───┘
             │
          [헤드]  ← 읽기/쓰기 헤드 (Head)
```

```
디스크 구조:

        트랙 (Track): 동심원 형태의 각 줄
         ↓
  ┌──────────────────────────────┐
  │    ○ ○ ○ ○ ○ ○ ○ ○ ○ ○     │  ← 섹터 (Sector): 최소 저장 단위
  │  ○                     ○    │
  │ ○   실린더 (Cylinder)   ○   │  ← 같은 트랙 번호들의 집합
  │  ○                     ○    │     (여러 플래터에 걸쳐 있음)
  │    ○ ○ ○ ○ ○ ○ ○ ○ ○ ○     │
  └──────────────────────────────┘
```

## 접근 시간 구성

- ✨ **탐색 시간(Seek Time): 헤드를 원하는 실린더로 이동하는 시간 — 가장 큰 비중**
- ✨ **회전 지연(Rotational Latency): 원하는 섹터가 헤드 아래까지 회전해 오는 시간**

```
전체 접근 시간 = 탐색 시간 + 회전 지연 + 전송 시간
                   (seek)      (rotational)   (transfer)
```

- 💬 **탐색 시간을 줄이는 것이 디스크 성능 최적화의 핵심 → 디스크 스케줄링 알고리즘**

---

## 디스크 대역폭 (Disk Bandwidth)

$$\text{Disk Bandwidth} = \frac{\text{전송된 총 바이트 수}}{\text{첫 번째 요청부터 마지막 전송 완료까지의 시간}}$$

- ℹ **목표: 탐색 시간 최소화 + 대역폭 최대화**
