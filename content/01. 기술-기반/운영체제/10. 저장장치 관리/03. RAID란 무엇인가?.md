> 여러 디스크를 묶어서 더 빠르게, 더 안전하게

---

## 문제: 디스크 하나는 느리고 위험하다

- 디스크 N개로 구성된 배열에서 고장 확률은 디스크 1개보다 N배 높다
- **예시**: MTBF = 100,000시간인 디스크 100개 배열
  - 배열의 MTBF = 100,000 / 100 = **1,000시간** (약 42일)

- [!] **디스크가 많을수록 전체 시스템의 신뢰성은 오히려 낮아진다**

---

## RAID (Redundant Arrays of Independent Disks)

- [I] **RAID: 여러 디스크를 조합해 성능(속도)과 신뢰성(안전성)을 동시에 높이는 기술**

두 가지 핵심 기법:

| 기법 | 목적 | 방법 |
|---|---|---|
| **스트라이핑 (Striping)** | 성능 향상 | 데이터를 여러 디스크에 분산 저장 |
| **미러링 (Mirroring)** | 신뢰성 향상 | 데이터를 다른 디스크에 동일하게 복제 |

---

## 스트라이핑 (Striping) — 성능

- [I] **비트 수준 스트라이핑: 한 바이트의 각 비트를 서로 다른 디스크에 저장**

```
8개 디스크:
바이트: 1  0  1  1  0  0  1  0
        ↓  ↓  ↓  ↓  ↓  ↓  ↓  ↓
디스크: 1  2  3  4  5  6  7  8
```

- [I] **블록 수준 스트라이핑: 파일을 블록 단위로 여러 디스크에 분산**
- ["] **병렬로 읽고 쓰므로 단일 디스크보다 훨씬 빠르다**

---

## 패리티 비트 (Parity Bit) — 신뢰성의 중간 단계

- [I] **패리티: 데이터 비트들의 XOR 값 — 디스크 하나가 망가져도 나머지로 복구 가능**

```
디스크1  디스크2  디스크3  패리티(디스크4)
  1        0        1         0   (1 XOR 0 XOR 1 = 0)
  1        1        0         0   (1 XOR 1 XOR 0 = 0)

디스크2 고장 시:
  복구: 1 XOR ? XOR 1 = 0  →  ? = 0  ← 복원 성공
```

---

## RAID 레벨

```
RAID 0: 스트라이핑만 (중복 없음)
  [D1][D2][D3][D4]  → 빠름, 안전하지 않음

RAID 1: 미러링만
  [D1][D1][D2][D2]  → 안전, 비쌈 (저장 공간 50% 낭비)

RAID 4: 블록 스트라이핑 + 패리티 전용 디스크
  [D1][D2][D3][P]

RAID 5: 블록 스트라이핑 + 패리티 분산 저장
  [D1][D2][P ][D3]  → 패리티 병목 해소
  [D1][P ][D2][D3]
  [P ][D1][D2][D3]

RAID 6: 이중 패리티
  [D1][D2][P1][P2]  → 디스크 2개 동시 고장 허용

RAID 0+1: 스트라이핑 후 미러링
RAID 1+0: 미러링 후 스트라이핑
```

| RAID 레벨 | 스트라이핑 | 미러링 | 패리티 | 특징 |
|---|:---:|:---:|:---:|---|
| **RAID 0** | ✓ | | | 빠름, 신뢰성 없음 |
| **RAID 1** | | ✓ | | 안전, 비쌈 |
| **RAID 4** | ✓ | | ✓ | 패리티 전용 디스크 |
| **RAID 5** | ✓ | | ✓ | 패리티 분산 저장 (실무 많이 사용) |
| **RAID 6** | ✓ | | ✓✓ | 이중 패리티 |
| **RAID 1+0** | ✓ | ✓ | | 미러링 후 스트라이핑 — 실무 선호 |

- ["] **RAID 1+0이 RAID 0+1보다 선호되는 이유: 디스크 하나 고장 시 같은 미러 그룹 내에서만 영향 → 복구 더 용이**

## 부트 블록 (Boot Block)

- [I] **부트스트랩 로더: 컴퓨터 전원 인가 시 가장 먼저 실행되는 초기 프로그램 — NVM 플래시 메모리에 저장**

```
전원 ON
  ↓
NVM(플래시)의 부트스트랩 로더 실행
  ↓
디스크의 부트 블록(부트 파티션)에서 OS 커널 로드
  ↓
OS 실행
```

- [i] **Windows에서 부트 파티션은 고정된 위치(known memory location)에 매핑된다**
