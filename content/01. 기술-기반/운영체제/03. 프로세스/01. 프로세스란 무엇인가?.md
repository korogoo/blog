> 프로그램과 프로세스는 전혀 다른 개념이다

---

## 문제: 프로그램을 실행하면 무슨 일이 벌어지는가?

하드 디스크에 저장된 `ls` 명령어 파일이 있다고 하자

이 파일을 터미널에 입력하는 순간, 무언가가 변한다

- [!] **저장된 파일(프로그램)과 실행 중인 상태(프로세스)는 다르다**

---

## 프로그램 vs 프로세스

- [I] **프로그램(Program): 디스크에 저장된 명령어들의 집합 - 수동적인 존재**
- [I] **프로세스(Process): 실행 중인 프로그램 - 능동적인 존재**

```
디스크: [ls 바이너리 파일]  ← 프로그램
           ↓ 실행
메모리: [ls 프로세스]       ← 프로세스
```

같은 프로그램을 두 번 실행하면? 프로세스가 두 개 생긴다

프로그램은 하나지만, 프로세스는 여러 개일 수 있다

---

## 프로세스는 어떤 자원을 필요로 하는가?

프로세스는 실행되기 위해 다음 자원들을 OS로부터 할당받는다

| 자원         | 설명                 |
| ---------- | ------------------ |
| **CPU 시간** | 명령어를 실행하기 위한 처리 능력 |
| **메모리**    | 코드와 데이터를 올려두는 공간   |
| **파일**     | 읽고 쓸 파일들           |
| **I/O 장치** | 키보드, 화면, 디스크 등     |

- [I] **프로세스는 OS가 관리하는 작업의 단위(unit of work)다**

---

## 프로세스와 스레드

프로세스는 기본적으로 **하나의 실행 흐름(single thread of execution)** 을 가진다

한 번에 하나의 작업만 처리할 수 있다는 뜻이다

<br/>

- [i] **현대 OS는 하나의 프로세스 안에 여러 스레드를 허용한다**

스레드는 가벼운 프로세스라고 부른다 (자세한 내용 스레드 파트에서 다룬다)
