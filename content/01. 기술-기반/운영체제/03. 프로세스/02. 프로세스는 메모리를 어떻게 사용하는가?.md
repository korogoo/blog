> 프로세스가 메모리에 올라갈 때, 아무렇게나 올라가지 않는다

---

## 문제: 코드, 변수, 함수 호출을 한 덩어리로 쌓으면 어떻게 되는가?

프로세스 안에는 다양한 종류의 데이터가 섞여 있다

- [>] 실행할 코드
- [>] 프로그램 시작부터 끝까지 유지되는 전역 변수
- [>] 실행 중 동적으로 생성되는 데이터
- [>] 함수 호출 때마다 생겼다 사라지는 임시 데이터

<br/>

- [!] **각 데이터의 성격이 달라서, 구역을 나눠 관리해야 한다**

---

## 프로세스의 메모리 구조

메모리는 낮은 주소에서 높은 주소 방향으로 구역이 나뉜다

```
높은 주소
┌──────────────┐
│  argc, argv  │  ← 프로그램 실행 인자
├──────────────┤
│              │
│    Stack     │  ↓ 아래로 자람
│              │
├──────────────┤
│      ↕       │  (빈 공간)
├──────────────┤
│              │
│     Heap     │  ↑ 위로 자람
│              │
├──────────────┤
│     Data     │  ← 전역 변수 (초기화 / 미초기화)
├──────────────┤
│     Text     │  ← 실행 코드 (읽기 전용)
└──────────────┘
낮은 주소
```

---

## 각 영역의 역할

| 영역 | 저장되는 것 | 특징 |
|---|---|---|
| **Text** | 실행 코드 (기계어) | 고정 크기, 읽기 전용 |
| **Data** | 전역 변수 | 초기화됨(data) / 미초기화(bss)로 나뉨 |
| **Heap** | `malloc`으로 동적 할당된 메모리 | 실행 중 크기 변화, 위로 자람 |
| **Stack** | 함수 파라미터, 지역 변수, 리턴 주소 | 함수 호출마다 자동 생성/제거, 아래로 자람 |

- [i] **Heap과 Stack은 서로를 향해 자란다**

둘이 만나면 메모리 오버플로우가 발생한다

---

## 코드로 확인하기

```c
#include <stdio.h>
#include <stdlib.h>

int x;           // 미초기화 전역 변수 → Data (BSS)
int y = 15;      // 초기화된 전역 변수 → Data

int main(int argc, char *argv[])
{
    int *values;       // 포인터 변수 자체  → Stack
    int i;             // 지역 변수         → Stack

    values = (int *)malloc(sizeof(int) * 5);  // 할당된 공간 → Heap

    for (i = 0; i < 5; i++)
        values[i] = i;

    return 0;
}
```

<br/>

컴파일 후 `size` 명령어로 각 영역 크기를 직접 확인할 수 있다

```bash
$ gcc 3.1_memory_layout.c
$ size ./a.out
text    data    bss     dec     hex     filename
1603    604     12      2219    8ab     ./a.out
```

| 항목 | 의미 |
|---|---|
| `text` | 코드 영역 크기 |
| `data` | 초기화된 전역 변수 크기 (`y = 15`가 여기에) |
| `bss` | 미초기화 전역 변수 크기 (`x`가 여기에) |
| `dec` | text + data + bss 합계 (10진수) |
