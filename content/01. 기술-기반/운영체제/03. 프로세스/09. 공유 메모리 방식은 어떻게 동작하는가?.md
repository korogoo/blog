> 두 프로세스가 같은 메모리를 함께 읽고 쓴다

---

## Producer-Consumer 문제

공유 메모리를 설명할 때 가장 많이 쓰이는 예시다

- [I] **Producer-Consumer 문제: 생산자가 데이터를 만들고, 소비자가 그것을 가져다 쓰는 구조**

<br/>

실제 사례

| 생산자 | 소비자 |
|---|---|
| 컴파일러 (어셈블리 코드 생성) | 어셈블러 (어셈블리 코드 소비) |
| 웹 서버 (HTML 생성) | 브라우저 (HTML 소비) |

---

## 해결: 공유 버퍼

생산자와 소비자 사이에 **버퍼(buffer)** 를 두면 된다

생산자는 버퍼에 넣고, 소비자는 버퍼에서 꺼낸다

- ["] **공유 메모리: 두 프로세스 모두 접근할 수 있는 메모리 영역**

```
생산자 프로세스                소비자 프로세스
      │                              │
      │  write                       │  read
      ▼                              ▼
┌─────────────────────────────────────┐
│           공유 버퍼 (Shared Buffer)  │
│  [ ][ ][A][B][C][ ][ ][ ][ ][ ]    │
│        ↑                 ↑          │
│      out               in           │
└─────────────────────────────────────┘
```

`in`: 생산자가 다음에 쓸 위치
`out`: 소비자가 다음에 읽을 위치

버퍼가 꽉 차면 생산자는 기다리고, 비어있으면 소비자는 기다린다

---

## 공유 버퍼 코드

```c
#define BUFFER_SIZE 10

typedef struct {
    ...
} item;

item buffer[BUFFER_SIZE];  // 공유 메모리 영역
int in = 0;                // 생산자가 쓸 위치
int out = 0;               // 소비자가 읽을 위치
```

**생산자**

```c
item next_produced;

while (true) {
    /* 아이템 생성 */
    while (((in + 1) % BUFFER_SIZE) == out)
        ;  // 버퍼가 꽉 찼으면 대기

    buffer[in] = next_produced;
    in = (in + 1) % BUFFER_SIZE;
}
```

**소비자**

```c
item next_consumed;

while (true) {
    while (in == out)
        ;  // 버퍼가 비었으면 대기

    next_consumed = buffer[out];
    out = (out + 1) % BUFFER_SIZE;
    /* 아이템 소비 */
}
```

- [i] **이 구현에서 버퍼를 꽉 채우면 BUFFER_SIZE - 1개까지만 사용한다**

`in == out`이면 비어있는 상태, `(in+1) % SIZE == out`이면 꽉 찬 상태로 구분하기 때문이다

## POSIX 공유 메모리 API

실제 시스템에서 공유 메모리를 사용하려면 OS의 API를 거쳐야 한다

POSIX 표준에서는 **메모리 매핑 파일(memory-mapped file)** 방식으로 구현한다

```
① shm_open()   → 공유 메모리 객체 생성/열기
② ftruncate()  → 크기 설정
③ mmap()       → 프로세스 주소 공간에 매핑
```

**생산자**

```c
#include <fcntl.h>
#include <sys/mman.h>

int main()
{
    const int SIZE = 4096;
    const char *name = "OS";

    /* 공유 메모리 객체 생성 */
    int shm_fd = shm_open(name, O_CREAT | O_RDWR, 0666);

    /* 크기 설정 */
    ftruncate(shm_fd, SIZE);

    /* 주소 공간에 매핑 */
    char *ptr = (char *)mmap(0, SIZE, PROT_READ | PROT_WRITE, MAP_SHARED, shm_fd, 0);

    /* 공유 메모리에 쓰기 */
    sprintf(ptr, "%s", "Hello, ");
    ptr += strlen("Hello, ");
    sprintf(ptr, "%s", "Shared Memory!\n");

    return 0;
}
// 컴파일: gcc producer.c -lrt
```

**소비자**

```c
int main()
{
    const int SIZE = 4096;
    const char *name = "OS";

    /* 기존 공유 메모리 열기 (읽기 전용) */
    int shm_fd = shm_open(name, O_RDONLY, 0666);

    /* 주소 공간에 매핑 */
    char *ptr = (char *)mmap(0, SIZE, PROT_READ | PROT_WRITE, MAP_SHARED, shm_fd, 0);

    /* 읽기 */
    printf("%s", (char *)ptr);

    /* 공유 메모리 제거 */
    shm_unlink(name);

    return 0;
}
// 컴파일: gcc consumer.c -lrt
```

- [i] **`shm_unlink()`는 공유 메모리 객체를 삭제한다 - 소비자가 다 읽은 후 정리**
