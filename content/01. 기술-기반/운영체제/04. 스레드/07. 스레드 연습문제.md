> fork()와 스레드가 함께 나오면 더 꼼꼼히 추적해야 한다

---

## 풀기 전에: 핵심 규칙 정리

▶ `fork()`: 프로세스 복제 — 주소 공간이 분리됨
▶ `pthread_create()`: 스레드 생성 — 같은 프로세스 안에서 주소 공간을 공유
▶ 같은 프로세스의 스레드들은 전역 변수를 공유한다
▶ `fork()`로 나뉜 부모-자식 프로세스는 전역 변수를 공유하지 않는다

---

## Exercise 4.19: 출력 결과는 무엇인가?

```c
int value = 0;

void *runner(void *param) {
    value = 5;
    pthread_exit(0);
}

int main() {
    pid_t pid;
    pthread_t tid;
    pthread_attr_t attr;

    pid = fork();

    if (pid == 0) {              // 자식 프로세스
        pthread_attr_init(&attr);
        pthread_create(&tid, &attr, runner, NULL);
        pthread_join(tid, NULL);
        printf("CHILD: value = %d\n", value);   // LINE C
    }
    else if (pid > 0) {          // 부모 프로세스
        wait(NULL);
        printf("PARENT: value = %d\n", value);  // LINE P
    }
}
```

**정답**

```
CHILD: value = 5
PARENT: value = 0
```

<br/>

**왜 그런가?**

💬 **`fork()` 이후 자식과 부모는 독립된 주소 공간을 가진다**

```
fork() 시점:
  부모: value = 0 (자신의 메모리)
  자식: value = 0 (복사된 메모리)

자식 프로세스 안에서:
  pthread_create() → runner 스레드 생성
  runner: value = 5 설정
  → 자식의 메모리에서 value가 5로 변경

  LINE C: CHILD: value = 5  ✓

부모 프로세스:
  자식이 수정한 건 자식의 메모리 — 부모의 value는 그대로 0

  LINE P: PARENT: value = 0  ✓
```

핵심 포인트 두 가지

▶ **스레드와 프로세스의 차이**: 스레드는 같은 프로세스 안에서 메모리를 공유하므로 `runner`가 수정한 `value`가 자식 프로세스의 `printf`에 반영된다
▶ **fork()의 주소 공간 복사**: 자식의 메모리 변경은 부모에게 영향을 주지 않는다
