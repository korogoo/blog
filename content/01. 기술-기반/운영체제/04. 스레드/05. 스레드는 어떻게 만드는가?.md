> 스레드를 직접 만들어보자 — C와 Java, 두 가지 방법

## Pthreads (C)

- ✨ **Pthreads: POSIX 표준(IEEE 1003.1c)으로 정의된 스레드 API — 명세(specification)이지, 구현체가 아니다**

UNIX 계열 OS(Linux, macOS 등)에서 구현체를 제공한다

```c
#include <pthread.h>

int sum;  // 스레드가 공유하는 전역 변수

void *runner(void *param) {
    int i, upper = atoi(param);
    sum = 0;
    for (i = 0; i <= upper; i++)
        sum += i;
    pthread_exit(0);
}

int main(int argc, char *argv[]) {
    pthread_t tid;         // 스레드 ID
    pthread_attr_t attr;   // 스레드 속성

    pthread_attr_init(&attr);
    pthread_create(&tid, &attr, runner, argv[1]);  // 스레드 생성
    pthread_join(tid, NULL);                        // 스레드 종료 대기
    printf("sum = %d\n", sum);
}
// 컴파일: gcc -pthread 4.11_pthread.c
```

핵심 함수

| 함수 | 역할 |
|---|---|
| `pthread_create()` | 스레드 생성 |
| `pthread_join()` | 해당 스레드가 끝날 때까지 대기 (Java의 `join()`과 동일) |
| `pthread_exit()` | 스레드 종료 |

## Java 스레드

Java에서 스레드를 만드는 방법은 세 가지다

---

### 방법 1: Thread 클래스 상속

```java
class MyThread extends Thread {
    public void run() {
        try {
            while (true) {
                System.out.println("Hello, Thread!");
                Thread.sleep(500);
            }
        } catch (InterruptedException ie) {
            System.out.println("I'm interrupted");
        }
    }
}

public class ThreadExample1 {
    public static void main(String[] args) {
        MyThread thread = new MyThread();
        thread.start();
        System.out.println("Hello, My Child!");
    }
}
```

---

### 방법 2: Runnable 인터페이스 구현

```java
class MyThread implements Runnable {
    public void run() {
        try {
            while (true) {
                System.out.println("Hello, Runnable!");
                Thread.sleep(500);
            }
        } catch (InterruptedException ie) {
            System.out.println("I'm interrupted");
        }
    }
}

public class ThreadExample2 {
    public static void main(String[] args) {
        Thread thread = new Thread(new MyThread());
        thread.start();
        System.out.println("Hello, My Runnable Child!");
    }
}
```

- ℹ **`Runnable` 구현이 `Thread` 상속보다 선호된다**

Java는 단일 상속만 가능하기 때문에, `Thread`를 상속하면 다른 클래스를 상속할 수 없다

---

### 방법 3: 람다 표현식 (Java 1.8+)

```java
public class ThreadExample3 {
    public static void main(String[] args) {
        Runnable task = () -> {
            try {
                while (true) {
                    System.out.println("Hello, Lambda Runnable!");
                    Thread.sleep(500);
                }
            } catch (InterruptedException ie) {
                System.out.println("I'm interrupted");
            }
        };

        Thread thread = new Thread(task);
        thread.start();
        System.out.println("Hello, My Lambda Child!");
    }
}
```

별도 클래스 없이 람다 표현식으로 `run()` 구현을 인라인으로 작성한다

## 부모 스레드의 대기: join()

프로세스의 `wait()`처럼, 스레드에서는 `join()`으로 자식 스레드가 끝날 때까지 기다린다

```java
Thread thread = new Thread(task);
thread.start();
try {
    thread.join();  // 스레드가 끝날 때까지 대기
} catch (InterruptedException ie) {
    System.out.println("Parent thread is interrupted");
}
System.out.println("Hello, My Joined Child!");
```

---

## 스레드 종료: interrupt()

- ⚠️ **`stop()`은 deprecated(사용 중단)되었다 — 스레드를 강제 종료하면 자원이 정리되지 않을 수 있다**

- 💬 **`interrupt()`로 스레드에게 종료 신호를 보내고, 스레드가 스스로 정리하고 끝내도록 한다**

```java
Thread thread = new Thread(task);
thread.start();
Thread.sleep(500);
thread.interrupt();  // 종료 요청 신호 전송
```

스레드 내부에서 `Thread.sleep()` 등 블로킹 중에 인터럽트가 오면
`InterruptedException`이 발생하고, 이를 catch해서 정상 종료 처리를 한다
