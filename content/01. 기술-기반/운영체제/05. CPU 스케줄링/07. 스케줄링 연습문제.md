> Gantt 차트를 직접 그려보는 것이 스케줄링을 이해하는 가장 빠른 방법이다

---

## 풀기 전에: 핵심 공식 정리

- ✨ **대기 시간 = 완료 시각 − 도착 시각 − CPU Burst 시간**
- ✨ **반환 시간 = 완료 시각 − 도착 시각**
- ✨ **응답 시간 = 처음 CPU를 받은 시각 − 도착 시각**

## Exercise 5.3

다음 프로세스들이 모두 시각 0에 도착한다고 가정한다 (우선순위: 숫자 낮을수록 높음)

| 프로세스 | CPU Burst | 우선순위 |
|---|---|---|
| P1 | 2ms | 2 |
| P2 | 1ms | 1 |
| P3 | 8ms | 4 |
| P4 | 4ms | 2 |
| P5 | 5ms | 3 |

각 알고리즘으로 스케줄링했을 때 Gantt 차트를 그리고, 평균 대기 시간을 구하시오

---

### a. FCFS

도착 순서 P1 → P2 → P3 → P4 → P5

```
 0   2   3          11          15          20
 ├───┤───┤──────────┤───────────┤───────────┤
 │P1 │P2 │    P3    │    P4     │    P5     │
```

| 프로세스 | 완료 | 대기 시간 |
|---|---|---|
| P1 | 2 | 0 |
| P2 | 3 | 2 |
| P3 | 11 | 3 |
| P4 | 15 | 11 |
| P5 | 20 | 15 |

평균 대기 시간: (0 + 2 + 3 + 11 + 15) / 5 = **6.2ms**

---

### b. 비선점 SJF

burst 짧은 순: P2(1) → P1(2) → P4(4) → P5(5) → P3(8)

```
 0   1   3       7          12          20
 ├───┤───┤───────┤───────────┤───────────┤
 │P2 │P1 │  P4   │    P5     │    P3     │
```

| 프로세스 | 완료 | 대기 시간 |
|---|---|---|
| P1 | 3 | 1 |
| P2 | 1 | 0 |
| P3 | 20 | 12 |
| P4 | 7 | 3 |
| P5 | 12 | 7 |

평균 대기 시간: (1 + 0 + 12 + 3 + 7) / 5 = **4.6ms**

---

### c. 비선점 Priority

우선순위 순: P2(1) → P1(2) = P4(2) → P5(3) → P3(4)
같은 우선순위 P1, P4는 FCFS로 → P1 먼저

```
 0   1   3       7          12          20
 ├───┤───┤───────┤───────────┤───────────┤
 │P2 │P1 │  P4   │    P5     │    P3     │
```

| 프로세스 | 완료 | 대기 시간 |
|---|---|---|
| P1 | 3 | 1 |
| P2 | 1 | 0 |
| P3 | 20 | 12 |
| P4 | 7 | 3 |
| P5 | 12 | 7 |

평균 대기 시간: (1 + 0 + 12 + 3 + 7) / 5 = **4.6ms**

- ℹ **이 예시에서 SJF와 Priority 결과가 같다 — 우연의 일치가 아니라 우선순위 배정이 burst 길이 역순과 일치하기 때문**

---

### d. RR (time quantum = 2ms)

```
 0   2   3   5   7   9  10  12  14  15  17  18  20
 ├───┤───┤───┤───┤───┤───┤───┤───┤───┤───┤───┤───┤
 │P1 │P2 │P3 │P4 │P5 │P3 │P4 │P5 │P3 │P5 │P3 │P3 │
```

| 프로세스 | 완료 | 대기 시간 |
|---|---|---|
| P1 | 2 | 0 |
| P2 | 3 | 2 |
| P3 | 20 | 12 |
| P4 | 12 | 8 |
| P5 | 17 | 12 |

평균 대기 시간: (0 + 2 + 12 + 8 + 12) / 5 = **6.8ms**

---

## 결과 비교

| 알고리즘 | 평균 대기 시간 |
|---|---|
| FCFS | 6.2ms |
| SJF (비선점) | 4.6ms |
| Priority (비선점) | 4.6ms |
| RR (q=2) | 6.8ms |

- 💬 **SJF가 평균 대기 시간 기준으로 최적 — 이론과 일치한다**
- ℹ **RR은 평균 대기 시간은 길지만, 응답 시간은 가장 짧다**

모든 프로세스가 2ms 안에 첫 번째 CPU를 받는다
