> 가장 단순한 방법과 이론적으로 최적인 방법

---

## FCFS: First-Come, First-Served

- [I] **FCFS: 먼저 온 프로세스에게 먼저 CPU를 할당한다 — FIFO 큐로 구현**

가장 단순한 알고리즘이며, **비선점** 방식이다

---

## FCFS 예시

| 프로세스 | CPU Burst |
|---|---|
| P1 | 24ms |
| P2 | 3ms |
| P3 | 3ms |

**도착 순서 P1 → P2 → P3일 때**

```
 0          24  27  30
 ├──────────────┤───┤───┤
 │     P1       │P2 │P3 │
```

| 프로세스 | 대기 시간 |
|---|---|
| P1 | 0 |
| P2 | 24 |
| P3 | 27 |

평균 대기 시간: (0 + 24 + 27) / 3 = **17ms**

<br/>

**도착 순서 P2 → P3 → P1일 때**

```
 0   3   6          30
 ├───┤───┤──────────────┤
 │P2 │P3 │      P1      │
```

| 프로세스 | 대기 시간 |
|---|---|
| P1 | 6 |
| P2 | 0 |
| P3 | 3 |

평균 대기 시간: (6 + 0 + 3) / 3 = **3ms**

- [!] **같은 프로세스 집합인데 순서만 달라져도 평균 대기 시간이 17ms → 3ms로 달라진다**

---

## Convoy Effect

- [I] **Convoy Effect: CPU burst가 긴 프로세스 뒤에 짧은 프로세스들이 줄지어 기다리는 현상**

CPU-bound 프로세스 하나 때문에 I/O-bound 프로세스들이 오래 기다리고,
그 결과 I/O 장치도 놀게 된다 → CPU와 I/O 장치 모두 활용률 저하

---

## SJF: Shortest-Job-First

- [I] **SJF: 다음 CPU burst가 가장 짧은 프로세스를 먼저 실행한다**

같은 burst 길이면 FCFS로 결정한다

**비선점** 방식 — 현재 실행 중인 프로세스는 끝날 때까지 CPU를 유지한다

---

## SJF 예시

| 프로세스 | CPU Burst |
|---|---|
| P1 | 6ms |
| P2 | 8ms |
| P3 | 7ms |
| P4 | 3ms |

실행 순서: P4(3) → P1(6) → P3(7) → P2(8)

```
 0   3       9          16          24
 ├───┤───────┤───────────┤───────────┤
 │P4 │  P1   │    P3     │    P2     │
```

| 프로세스 | 대기 시간 | 반환 시간 |
|---|---|---|
| P1 | 3 | 9 |
| P2 | 16 | 24 |
| P3 | 9 | 16 |
| P4 | 0 | 3 |

평균 대기 시간: (3 + 16 + 9 + 0) / 4 = **7ms**
평균 반환 시간: (9 + 24 + 16 + 3) / 4 = **13ms**

- ["] **SJF는 평균 대기 시간을 최소화한다 — 수학적으로 증명된 최적 알고리즘**

짧은 프로세스를 앞으로 보내면 그 프로세스의 대기 시간이 크게 줄고,
긴 프로세스의 대기 시간 증가는 상대적으로 작다

## 문제: 다음 CPU burst를 어떻게 아는가?

- [!] **실제로는 다음 CPU burst 길이를 미리 알 수 없다**

그래서 과거 CPU burst 기록을 이용해 **예측** 한다

### 지수 평균 (Exponential Average)

$$\tau_{n+1} = \alpha \cdot t_n + (1 - \alpha) \cdot \tau_n$$

- $t_n$: 실제 n번째 CPU burst 길이
- $\tau_{n+1}$: 다음 CPU burst 예측값
- $\alpha$: 최근 기록과 과거 기록 사이의 가중치 (0 ≤ α ≤ 1)

| α 값 | 의미 |
|---|---|
| α = 1 | 직전 burst만 반영 |
| α = 0 | 과거 평균만 반영, 최근 무시 |
| α = 1/2 | 최근과 과거를 동등하게 반영 |

- [i] **α = 1/2이 가장 많이 쓰이며, 최근 이력과 오래된 이력을 균등하게 고려한다**
