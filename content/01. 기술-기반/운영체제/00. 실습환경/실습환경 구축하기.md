> C/C++ 코드를 컴파일하고 디버깅할 수 있는 기본 세팅

> VS Code에서 파일을 편집하면 그게 곧바로 컨테이너 안에 저장되고, 컨테이너 터미널에서 `gcc`로 컴파일하고 `gdb`로 디버깅할 수 있게됨.


<br/>

## 1. 도커를 이용하여 Ubuntu 설치

도커는 설치되었다고 가정함

- [>] **ubuntu 이미지 다운로드 및 컨테이너 실행**
```bash
$ docker pull ubuntu:20.04
$ docker run -it --name myUbuntu ubuntu:20.04
```

- [>] **도커 컨테이너 내로 들어옴**
```bash
$ apt-get update # 설치 가능한 패키지 목록 갱신
$ apt-get upgrade -y # 패키지 업그레이드 (교수님은 생략하심)
$ apt-get install build-essential gdb
```

- `build-essential`: gcc/g++ 컴파일러 등 C/C++ 개발 필수 도구 묶음
- `gdb`: 디버거 (중단점 찍고 변수 값 보면서 디버깅하는 도구)

## 2. VS Code에서 Container에 연결함

> 컨테이너 안에서 `vim`이나 `nano` 같은 터미널 에디터로 코딩하는 건 불편함
> 
> 그래서 **내 컴퓨터의 VS Code로 컨테이너 안의 파일을 편집**할 수 있게 연결

<br/>

- [>] **VS Code 에서 Remote - Container 플러그인 설치**
	- VS Code가 컨테이너 내부에 접근할 수 있게 해주는 확장 프로그램

<br/>

- [>] **설치 후 좌측 하단에 >< 아이콘의 초록색 버튼 클릭**
	- 원격 연결 메뉴를 여는 버튼

<br/>

- [>] **메뉴 클릭 Attach to Running Container…** 
	- 지금 실행 중인 컨테이너(myUbuntu)에 VS Code를 붙이는 것

<br/>

- [>] 테스트

> Vs Code에서 텍스트 파일 생성하고 컨테이너 내에서 확인해보면 파일 생성되어 있음
