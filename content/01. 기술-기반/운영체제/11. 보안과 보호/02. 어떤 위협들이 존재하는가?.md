## 프로그램 위협 (Program Threats)

### 악성 소프트웨어 (Malware)

- ✨ **Malware: 컴퓨터 시스템을 악용·비활성화·손상시키기 위해 설계된 소프트웨어**

| 종류 | 설명 |
|---|---|
| **트로이 목마** (Trojan Horse) | 정상 프로그램인 척하며 악성 행위 수행 |
| **스파이웨어** (Spyware) | 사용자 정보를 몰래 수집·전송 |
| **랜섬웨어** (Ransomware) | 파일을 암호화하고 복호화 대가로 금전 요구 |
| **백도어** (Backdoor) | 인증 절차를 우회하는 숨겨진 접근 통로 |
| **논리 폭탄** (Logic Bomb) | 특정 조건 충족 시 악성 행위 실행 |

---

### 코드 인젝션 (Code Injection)

- ✨ **코드 인젝션: 악성 코드를 입력값으로 주입해 프로그램이 의도치 않은 코드를 실행하게 만드는 공격**

```
예시 — SQL Injection:
  정상 쿼리: SELECT * FROM users WHERE id='입력값'
  공격 입력: ' OR '1'='1
  결과 쿼리: SELECT * FROM users WHERE id='' OR '1'='1'
                                              ↑
                                       항상 참 → 모든 계정 접근
```

- ℹ **프로그램 자체는 악의적이지 않아도 입력 검증 부재로 심각한 위협이 된다**

---

### 바이러스와 웜 (Virus & Worm)

| 항목 | 바이러스 (Virus) | 웜 (Worm) |
|---|---|---|
| **정의** | 정상 프로그램에 숨어드는 코드 조각 | 독립적으로 실행되는 자기복제 프로그램 |
| **전파 방법** | 감염된 파일을 사람이 실행 | 네트워크를 통해 자동 전파 |
| **사람 개입** | 필요 | 불필요 |

## 시스템 및 네트워크 위협

### 네트워크 트래픽 공격

- ✨ **스니핑(Sniffing): 네트워크 트래픽을 수동으로 도청하는 공격 — 공격자는 패시브 상태**

```
A ──────────────────────────────► B
         │
         └─ [스니퍼] 몰래 복사해서 읽음
```

- ✨ **스푸핑(Spoofing): 공격자가 통신 당사자 중 하나인 척하거나, 중간에서 가로채고 조작하는 공격**

```
A ──────► [공격자] ──────► B
          ↑ 양쪽에게 상대방인 척
          MITM (Man-in-the-Middle)
```

---

### 서비스 거부 (DoS / DDoS)

- ✨ **DoS(Denial of Service): 시스템을 과부하시켜 정상 사용자가 서비스를 이용하지 못하게 방해**
- ✨ **DDoS(Distributed DoS): 수많은 좀비 PC를 동원해 분산 공격**

```
정상 사용자 ──►  │
                 │ 서버 과부하
공격자 ────────► │ (서비스 불가)
공격자 ────────► │
공격자 ────────► │
   (수천~수만 개)
```

- 💬 **정보 탈취나 자원 도용이 목적이 아니라, 서비스 방해 자체가 목적**

---

### 포트 스캐닝 (Port Scanning)

- ✨ **포트 스캐닝: 공격 대상 시스템에서 열려 있는 포트를 탐색해 취약점을 찾는 행위**

```
공격자 → 80번 포트: 열림 (HTTP)
        443번 포트: 열림 (HTTPS)
        22번 포트:  열림 (SSH) ← 취약점 탐색 대상
        3306번 포트: 열림 (MySQL) ← 위험!
```

- ℹ **포트 스캐닝 자체는 공격이 아니지만, OS 종류와 서비스를 파악(fingerprinting)하는 사전 정찰 단계다**
