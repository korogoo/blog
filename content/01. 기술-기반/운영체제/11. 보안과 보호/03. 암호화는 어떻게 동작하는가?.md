> 키를 가진 사람만 읽을 수 있다 — 네트워크를 신뢰하지 않아도 된다

---

## 암호화의 역할

- ["] **암호학의 목적: 네트워크를 신뢰할 필요 없게 만드는 것**

아무리 도청해도 키 없이는 해독 불가
→ 안전하지 않은 네트워크에서도 안전한 통신 가능

---

## 암호화 알고리즘의 구성 요소

- 키 집합 $K$, 메시지 집합 $M$, 암호문 집합 $C$
- 암호화 함수 $E: K \rightarrow (M \rightarrow C)$
- 복호화 함수 $D: K \rightarrow (C \rightarrow M)$

**핵심 성질:**

$$E_k(m) = c \quad \Longrightarrow \quad D_k(c) = m$$

- [!] **키 없이는 암호문에서 평문을 복원하는 것이 계산적으로 불가능해야 한다**

---

## 대칭 암호화 (Symmetric Encryption)

- [I] **대칭 암호화: 암호화와 복호화에 같은 키를 사용하는 방식**

```
송신자                              수신자
평문 ──[암호화: E_k]──► 암호문 ──[복호화: D_k]──► 평문
              ↑                          ↑
           같은 키 k                  같은 키 k
```

- 키를 두 사람이 미리 공유해야 한다
- **키 교환 방법**: 직접 전달 또는 신뢰할 수 있는 제3자(인증 기관, CA)를 통해

| 알고리즘 | 설명 |
|---|---|
| **DES** (Data Encryption Standard) | 과거 표준, 56비트 키 — 현재 안전하지 않음 |
| **AES** (Advanced Encryption Standard) | 현재 표준, 128/192/256비트 키 |

- [i] **대칭 암호화는 빠르지만, 키를 안전하게 전달하는 것이 문제**

---

## 비대칭 암호화 (Asymmetric Encryption)

- [I] **비대칭 암호화: 암호화와 복호화에 서로 다른 키(공개 키/개인 키)를 사용하는 방식**

```
키 쌍 생성:
  공개 키 (Public Key)  → 누구에게나 공개
  개인 키 (Private Key) → 자신만 보관

암호화:
  송신자 → 수신자의 공개 키로 암호화 → 암호문 전송
  수신자 → 자신의 개인 키로 복호화

누가 도청해도 공개 키만으로는 복호화 불가
```

- ["] **키를 미리 공유하지 않아도 된다 — 공개 키는 공개해도 안전하다**

---

## RSA 알고리즘

- [I] **RSA: 가장 널리 사용되는 비대칭 암호화 알고리즘 (Rivest, Shamir, Adleman)**

```
원리 (간략):
  두 큰 소수 p, q를 선택
  n = p × q  (공개)
  개인 키: p, q를 아는 사람만 복호화 가능
  공개 키만으로 p, q를 알아내는 것은 수학적으로 매우 어려움
  (소인수분해 문제)
```

| | 대칭 암호화 | 비대칭 암호화 |
|---|---|---|
| **키 수** | 1개 (공유) | 2개 (공개/개인) |
| **속도** | 빠름 | 느림 |
| **키 배포** | 어려움 | 쉬움 |
| **대표 알고리즘** | AES | RSA |

- [i] **실제로는 비대칭으로 키를 교환하고, 이후 통신은 대칭으로 하는 하이브리드 방식을 사용한다 (TLS/HTTPS)**
