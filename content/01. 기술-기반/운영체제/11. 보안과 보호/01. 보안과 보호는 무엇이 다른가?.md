> 보안은 외부 위협을 막고, 보호는 내부 접근을 통제한다

---

## 보안 (Security) vs 보호 (Protection)

- [I] **보안(Security): 사용자를 인증하고, 데이터·코드의 무결성과 물리적 자원을 외부 위협으로부터 지키는 것**
- [I] **보호(Protection): OS로부터 적절한 권한을 부여받은 프로세스만 메모리, CPU, 자원에 접근할 수 있도록 제어하는 것**

| 항목 | 보안 (Security) | 보호 (Protection) |
|---|---|---|
| **대상** | 외부 공격자, 악의적 사용자 | 내부 프로세스/사용자 |
| **관심사** | 누가 시스템에 들어오는가 | 들어온 뒤 무엇을 할 수 있는가 |
| **수단** | 암호화, 인증, 방화벽 | 접근 권한, ACL, 샌드박스 |

---

## 보안 위협의 유형 (Security Violations)

- [I] **위협(Threat): 보안 침해의 가능성 — 우발적(accidental)**
- [I] **공격(Attack): 보안을 깨려는 의도적 시도 — 악의적(malicious)**

| 유형 | 설명 |
|---|---|
| **기밀성 침해** (Breach of Confidentiality) | 허가 없이 데이터를 읽거나 탈취 |
| **무결성 침해** (Breach of Integrity) | 데이터를 허가 없이 수정 |
| **가용성 침해** (Breach of Availability) | 합법적 사용자가 자원을 사용하지 못하게 방해 |
| **서비스 탈취** (Theft of Service) | 자원을 무단으로 사용 |
| **서비스 거부** (DoS / DDoS) | 시스템을 과부하시켜 정상 서비스 방해 |

---

## 보안의 4계층

```
┌──────────────────────────────┐
│       애플리케이션 (Application)  │  ← 보안 버그 포함 가능
├──────────────────────────────┤
│       운영체제 (OS)            │  ← 공격 표면 최소화, 침투 방지
├──────────────────────────────┤
│       네트워크 (Network)        │  ← 네트워킹 자체가 보안 위협
├──────────────────────────────┤
│       물리 (Physical)          │  ← 물리적 침입 방지
└──────────────────────────────┘
```

- ["] **가장 하위 계층이 뚫리면 상위 계층의 보안은 의미 없다**
- [i] **암호학(Cryptography)은 이 모든 계층에서 핵심 보안 도구로 사용된다**
