## 발단

영속성 컨텍스트는 JPA 엔티티만 관리한다

그러면 도메인 객체와 JPA 엔티티를 분리했을 때 어떤 구조가 되는 걸까? Mapper 패턴은 왜 쓰는 걸까?

## 무제

얻는 것
  - JPA 교체 시 domain 레이어는 건드릴 필요 없음
  - 도메인 엔티티가 순수 비즈니스 로직만 담아 읽기 편함

  잃는 것
  - 매퍼 코드가 추가됨 (변환 비용)
  - 클래스가 두 배로 늘어나서 초기 구현 복잡도 증가
  - 1차 MVP 수준에서는 오버엔지니어링일 수 있음
