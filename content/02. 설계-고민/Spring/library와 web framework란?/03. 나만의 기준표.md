> library는 내가 부르고, framework는 나를 부른다  
> ==통제권의 방향이 결정적 차이다==

---

## 구분 기준

```
이 코드를 내가 원하는 시점에 호출하는가?
         │
    ┌────┴────┐
    Yes       No (framework가 호출)
    │         │
  library   framework
```

---

## 정리

| | library | framework |
|--|---------|-----------|
| 통제권 | 나 | framework |
| 호출 방향 | 내가 라이브러리를 호출 | framework가 내 코드를 호출 |
| 예시 | Stream API, Jackson, Guava | Spring Boot, Django, Rails |

---

## Spring Boot에서 보이는 IoC

`@GetMapping("/hello")`를 붙이면 HTTP 요청이 들어올 때 Spring이 그 메서드를 호출한다

내가 직접 호출하지 않는다 — Spring이 제어한다

이것이 제어의 역전(IoC, Inversion of Control)이다

---

## 실전 체크리스트

- [I] **Spring이 내 코드를 언제, 왜 호출하는지 이해하고 있는가?**

`@Controller`, `@Service`, `@Repository` 같은 어노테이션이 Spring에게 역할을 알려주는 수단이다

<br/>

- [I] **사용하는 것이 library인지 framework인지 구분할 수 있는가?**

Jackson은 내가 직접 쓰는 library다

Spring은 내 코드를 품고 실행하는 framework다
