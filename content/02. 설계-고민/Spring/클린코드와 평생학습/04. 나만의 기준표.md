> 클린코드는 미래의 나와 팀원을 위한 배려다  
> ==지금 이 파일을 쓰는 행위 자체가 평생학습의 실천이다==

---

## 클린코드를 지향하는 이유

```
코드를 쓰는 시간 < 코드를 읽는 시간  (10:1 이상)
```

읽기 쉬운 코드 → 변경 비용 낮음 → 팀 속도 상승

---

## 클린코드 판단 기준

| 질문 | 판단 |
|------|------|
| 처음 보는 사람이 10분 안에 이해할 수 있는가? | ✅ 좋다 |
| 메서드 이름만으로 무엇을 하는지 알 수 있는가? | ✅ 좋다 |
| 이 코드를 수정하려면 다른 파일 3개를 먼저 이해해야 하는가? | ⚠️ 검토 |
| 기능 하나를 추가했는데 다른 곳이 터졌는가? | ⚠️ 검토 |

---

## 평생학습 실천 기준표

| 습관 | 구체적인 행동 |
|------|-------------|
| 작은 것 깊게 이해하기 | 동작만 확인하고 넘기지 않는다. "왜?"를 한 번 더 묻는다 |
| 모르는 것 기록하기 | 이 파일처럼 질문을 글로 남긴다 |
| 직접 짜보기 | 강의를 듣는 것과 직접 짜는 것은 다르다 |
| 설명해보기 | 말로 설명할 수 없으면 아직 모르는 것이다 |

---

## 실전 체크리스트

- ✨ **동작은 하는데 왜 동작하는지 모르는 코드가 있는가?**

멈추고 찾아본다. 그 순간이 배움이다

<br/>

- ✨ **코드 리뷰에서 같은 지적을 두 번 받았는가?**

기록하지 않았기 때문이다. 이유와 함께 정리해둔다

<br/>

- ✨ **"나중에 정리하자"고 미뤄둔 개념이 있는가?**

지금 이 파일처럼 짧게라도 써둔다. 나중은 오지 않는다
