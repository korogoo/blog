
> 로그는 프로그램이 남기는 일기다  
> ==읽는 습관이 곧 디버깅 실력이다==

---

## 예시 로그

```
INFO 93538 --- [ Test worker] o.s.b.w.embedded.tomcat.TomcatWebServer : Tomcat initialized with port 8080 (http)
```

---

## 구조 분해

```
[레벨] [PID] --- [스레드명] [로거명] : [메시지]
```

| 부분 | 예시 값 | 의미 |
|------|---------|------|
| 레벨 | `INFO` | 로그의 심각도 |
| PID | `93538` | 현재 프로세스 ID |
| 스레드명 | `Test worker` | 이 로그를 출력한 스레드 |
| 로거명 | `o.s.b.w.embedded.tomcat.TomcatWebServer` | 출력한 클래스 (패키지 축약) |
| 메시지 | `Tomcat initialized with port 8080 (http)` | 실제 내용 |

---

## 로거명 읽기

`o.s.b.w.embedded.tomcat.TomcatWebServer`는 패키지가 길어서 축약한 것이다

풀어서 쓰면:

`org.springframework.boot.web.embedded.tomcat.TomcatWebServer`

→ Spring Boot가 내장 Tomcat 웹서버를 초기화했다는 의미다

---

## 실행 시 주요 로그 흐름

```
Starting [ApplicationName]               → 애플리케이션 시작
Tomcat initialized with port 8080        → 내장 톰캣이 8080 포트로 준비됨
Starting Servlet engine: [Apache Tomcat] → 서블릿 엔진 시작
Initialized JPA EntityManagerFactory    → JPA 설정 완료 (DB 연동 시)
Started [ApplicationName] in 2.345s     → 실행 완료, 걸린 시간 표시
```

---

## 로그 레벨

| 레벨 | 의미 |
|------|------|
| `ERROR` | 오류. 반드시 확인해야 함 |
| `WARN` | 경고. 문제가 될 수 있음 |
| `INFO` | 일반 정보. 실행 흐름 확인용 |
| `DEBUG` | 상세 정보. 개발 시 문제 추적용 |
| `TRACE` | 가장 상세. 거의 안 씀 |

---

## 핵심

오류가 났을 때 `ERROR`와 `WARN`을 먼저 찾는다

그 주변의 `INFO`를 읽으면 어느 시점에 무슨 일이 있었는지 흐름을 파악할 수 있다

로그를 무시하지 않는 습관이 쌓이면, 처음 보는 오류도 읽어낼 수 있게 된다
