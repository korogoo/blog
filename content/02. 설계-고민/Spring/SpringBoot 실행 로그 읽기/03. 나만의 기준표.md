> 오류가 나면 ERROR부터 찾고, 그 주변 INFO를 읽으면 흐름이 보인다  
> ==로그는 위에서 아래로 시간 순이다==

---

## 로그 레벨 우선순위

```
ERROR  →  WARN  →  INFO  →  DEBUG  →  TRACE
(심각)                               (상세)
```

오류 상황에서는 `ERROR`, `WARN`을 먼저 찾는다

---

## 실행 흐름 기준표

| 로그 메시지 | 의미 |
|------------|------|
| `Starting [App]` | 애플리케이션 시작 |
| `Tomcat initialized with port 8080` | 내장 웹서버 준비 완료 |
| `Initialized JPA EntityManagerFactory` | DB 연결 및 JPA 설정 완료 |
| `Started [App] in 2.3s` | 실행 완료 |
| `ERROR ... could not execute statement` | DB 쿼리 실패 |

---

## 실전 체크리스트

- ✨ **서버가 뜨지 않는가?**

`ERROR`나 `WARN`이 있는 줄을 먼저 찾는다

포트 충돌, DB 연결 실패, Bean 생성 실패가 대부분이다

<br/>

- ✨ **로거명을 읽기 어려운가?**

`o.s.b.w` = `org.springframework.boot.web` 처럼 패키지를 축약한 것이다

어느 클래스에서 나온 로그인지 알면 원인 파악이 빠르다

<br/>

- ✨ **DEBUG 로그를 더 보고 싶은가?**

`application.properties`에서 레벨을 낮춘다

```properties
logging.level.org.springframework=DEBUG
```
