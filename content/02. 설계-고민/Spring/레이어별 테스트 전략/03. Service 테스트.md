> Service 테스트는 비즈니스 로직만 빠르게 검증한다  
> ==Spring 컨텍스트 없이 순수 Mockito만으로 충분하다==

---

## 기본 구조

```java
@ExtendWith(MockitoExtension.class)
class MemberServiceTest {

    @Mock
    private MemberRepository memberRepository;

    @InjectMocks
    private MemberService memberService;

    @Test
    void 존재하지_않는_회원을_조회하면_예외가_발생한다() {
        given(memberRepository.findById(99L))
            .willReturn(Optional.empty());

        assertThatThrownBy(() -> memberService.findById(99L))
            .isInstanceOf(MemberNotFoundException.class);
    }
}
```

---

## 각 구성요소

- [I] **`@ExtendWith(MockitoExtension.class)`**

Spring 컨텍스트 없이 순수 Mockito를 사용할 수 있게 해주는 JUnit 확장이다

애플리케이션 전체를 로딩하지 않으므로 빠르다

<br/>

- [I] **`@Mock`**

Spring과 무관하게 Mockito가 만드는 가짜 객체다

`memberRepository.findById()`가 어떻게 동작할지를 `given()`으로 정의해서 쓴다

<br/>

- [I] **`@InjectMocks`**

테스트 대상 클래스(`MemberService`)에 `@Mock`으로 만든 가짜 객체를 직접 주입한다

Spring의 `@Autowired`가 아닌 Mockito가 직접 주입을 처리한다

---

## @SpringBootTest를 쓰지 않는 이유

```
@SpringBootTest 사용 시 올라오는 것들:
  - Spring 컨텍스트 전체
  - JPA, Hibernate 설정
  - DataSource, Connection Pool
  - 모든 @Bean 등록
  → 수 초가 걸린다
```

Service 비즈니스 로직을 검증하는 데는 이 모든 것이 필요 없다

`@ExtendWith(MockitoExtension.class)`는 밀리초 단위로 실행된다

---

## 테스트 속도 비교

| 방식 | 실행 시간 |
|------|---------|
| `@SpringBootTest` | 수 초 (컨텍스트 로딩 포함) |
| `@ExtendWith(MockitoExtension.class)` | 밀리초 (컨텍스트 없음) |
