> 하나의 컴퓨터에는 수많은 프로그램이 동시에 네트워크를 쓴다  
> ==포트는 같은 IP 안에서 어떤 프로그램에게 데이터를 전달할지 구분하는 번호다==

---

## 포트가 왜 필요한가?

브라우저도, 카카오톡도, 게임도 모두 인터넷을 쓴다

IP 주소만으로는 어느 프로그램에게 데이터를 전달해야 할지 알 수 없다

✨ **아파트 동호수와 같다**

아파트 주소(IP)가 같아도, 101호와 102호(port)는 다른 집이다

---

## 잘 알려진 포트 번호들

| 포트 | 용도 |
|------|------|
| 80 | HTTP (일반 웹) |
| 443 | HTTPS (보안 웹) |
| 22 | SSH |
| 3306 | MySQL |
| 5432 | PostgreSQL |

---

## 왜 8080인가?

포트 80은 HTTP 표준 포트다

하지만 1024 미만 포트는 운영체제에서 관리자 권한을 요구한다

개발 환경에서는 권한 없이 쓸 수 있는 `8080`을 관례적으로 사용한다

Spring Boot의 기본값이 `8080`인 이유다

바꾸고 싶다면 `application.properties`에서 설정한다

```properties
server.port=9090
```

---

## URL 읽는 법

`http://localhost:8080/api/hello`

| 부분 | 의미 |
|------|------|
| `http://` | HTTP 프로토콜로 |
| `localhost` | 내 컴퓨터에 |
| `:8080` | 8080번 문으로 |
| `/api/hello` | 이 경로를 요청한다 |
