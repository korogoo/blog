> localhost는 내 컴퓨터, port는 그 안의 문 번호다  
> ==주소는 "어디", 포트는 "어느 프로그램에게"를 결정한다==

---

## 정리

| 표현 | 의미 |
|------|------|
| `localhost` | 내 컴퓨터 자신 |
| `127.0.0.1` | localhost의 IP 주소 (동일) |
| `:8080` | 8080번 포트 (문 번호) |
| `http://localhost:8080/api` | 내 컴퓨터 8080번 포트의 `/api` 경로 |

---

## 포트 충돌 해결

서버를 띄울 때 `Port 8080 was already in use` 오류가 나면

다른 프로세스가 8080 포트를 사용 중인 것이다

```properties
# application.properties에서 포트 변경
server.port=9090
```

또는 해당 프로세스를 종료한다

---

## 실전 체크리스트

- [I] **서버가 뜨지 않고 포트 충돌 오류가 나는가?**

`application.properties`에서 `server.port`를 다른 번호로 바꾼다

<br/>

- [I] **여러 Spring Boot 앱을 동시에 띄울 때는?**

각각 다른 포트를 써야 한다. 포트는 한 컴퓨터에서 하나의 프로세스만 사용할 수 있다

<br/>

- [I] **`localhost`에서는 되는데 다른 컴퓨터에서 안 되는가?**

localhost는 내 컴퓨터 안에서만 유효하다. 다른 컴퓨터에서 접근하려면 실제 IP가 필요하다
