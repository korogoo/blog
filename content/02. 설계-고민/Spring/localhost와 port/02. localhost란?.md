> localhost는 특별한 도메인 이름이다  
> =="내 컴퓨터 자신"을 가리키며, IP 주소로는 127.0.0.1이다==

---

## 정의

인터넷에서 컴퓨터를 구분할 때 IP 주소를 쓴다

`localhost`는 IP 주소 `127.0.0.1`에 연결된 이름으로,  
"이 컴퓨터 안에서 나 자신에게 요청을 보낸다"는 의미다

---

## 왜 필요한가?

Spring Boot를 실행하면 내 컴퓨터 안에 서버가 켜진다

그 서버에 접속하려면 주소가 필요한데,  
아직 인터넷에 올라간 게 아니라 내 컴퓨터 안에만 있기 때문에 `localhost`를 쓴다

- [I] **브라우저에서 `http://localhost:8080`을 치면**

내 컴퓨터(localhost)의 8080번 문(port)에 요청을 보내라는 뜻이다

---

## 비유

편지를 보낼 때 주소가 필요하다

`localhost`는 "나 자신에게 보내는 편지"다

수신인과 발신인이 같다

---

## 정리

| 표현 | 의미 |
|------|------|
| `localhost` | 내 컴퓨터 자신 |
| `127.0.0.1` | localhost의 IP 주소 (같은 의미) |
| `http://localhost:8080` | 내 컴퓨터의 8080번 포트에 HTTP 요청 |

---

## 핵심

개발할 때는 항상 내 컴퓨터에서 먼저 테스트한다

실제 서비스가 되면 `localhost` 대신 실제 서버의 IP나 도메인 주소로 바뀐다
