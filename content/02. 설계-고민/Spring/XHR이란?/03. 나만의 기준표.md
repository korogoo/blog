> XHR과 fetch()는 목적이 같고, 문법이 다른 것이다  
> ==개발자 도구 Network → XHR 탭이 백-프론트 통신 디버깅의 시작점이다==

---

## 정리

| | XHR | fetch() |
|--|-----|---------|
| 등장 시기 | 구식 (1999~) | 현대적 (2015~) |
| 코드 스타일 | 콜백 기반 | Promise 기반 |
| 현재 사용 | 레거시 코드에서 | 대부분의 신규 코드 |
| 브라우저 탭 분류 | XHR 필터에 표시 | XHR 필터에 표시 |

---

## 개발자 도구 활용법

```
F12 → Network 탭 → XHR 필터 → API 요청 클릭
    → Headers: 요청 URL, 메서드, 응답 상태코드 확인
    → Payload: 보낸 JSON 확인
    → Response: 받은 JSON 확인
```

---

## 실전 체크리스트

- ✨ **API를 호출했는데 응답이 이상한가?**

Network → XHR에서 해당 요청을 찾아 Response 탭을 확인한다

<br/>

- ✨ **요청이 아예 안 가는가?**

Network 탭에 요청 자체가 없으면 프론트 코드 문제다

요청은 있는데 오류 응답이 오면 백엔드 문제다

<br/>

- ✨ **CORS 오류가 나는가?**

Network 탭에 빨간색으로 표시된다. Console 탭도 함께 확인한다
