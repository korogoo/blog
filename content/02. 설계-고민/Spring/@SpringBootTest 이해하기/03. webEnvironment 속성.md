> @SpringBootTest는 어떤 환경으로 컨테이너를 올릴지 선택할 수 있다  
> ==webEnvironment 속성이 그 선택을 결정한다==

---

## webEnvironment 속성

```java
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
```

Spring Boot 애플리케이션을 테스트할 때 웹 서버를 어떻게 띄울지 설정한다

---

## 종류

- [I] **MOCK (기본값)**

```java
@SpringBootTest  // webEnvironment 생략 시 MOCK
```

실제 웹 서버를 띄우지 않는다

Servlet 컨테이너를 Mock으로 대체한다

`MockMvc`와 함께 사용한다

HTTP 요청/응답 흐름을 테스트하되, 실제 포트는 필요 없을 때 쓴다

<br/>

- [I] **RANDOM_PORT**

```java
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
```

실제 내장 웹 서버를 랜덤 포트로 띄운다

`TestRestTemplate`이나 `WebTestClient`와 함께 사용한다

실제 HTTP 요청을 보내는 통합 테스트에 적합하다

포트가 랜덤이라 테스트 간 충돌이 없다

<br/>

- [I] **DEFINED_PORT**

8080 같은 정해진 포트로 실제 서버를 띄운다

포트 충돌 가능성이 있어서 잘 쓰지 않는다

<br/>

- [I] **NONE**

웹 관련 설정을 일절 로딩하지 않는다

Service, Repository 계층만 테스트할 때 사용한다

---

## 비교

| 속성 | 실제 서버 | 포트 | 주요 사용 도구 |
|------|-----------|------|--------------|
| `MOCK` | X | 없음 | MockMvc |
| `RANDOM_PORT` | O | 랜덤 | TestRestTemplate |
| `DEFINED_PORT` | O | 고정 | TestRestTemplate |
| `NONE` | X | 없음 | 직접 주입 |

---

## 핵심

컨트롤러까지 포함한 통합 테스트라면 `RANDOM_PORT`가 실제 HTTP 흐름을 검증할 수 있다

웹 레이어 없이 비즈니스 로직만 검증하려면 `NONE` 또는 `MOCK`이 빠르다

테스트 목적에 따라 선택하는 것이 맞다
