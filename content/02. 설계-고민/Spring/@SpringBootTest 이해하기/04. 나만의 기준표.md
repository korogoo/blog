> @SpringBootTest는 강력하지만 무겁다  
> ==테스트 목적에 따라 더 가벼운 슬라이스 테스트를 우선 고려한다==

---

## webEnvironment 선택 기준

```
무엇을 테스트하려 하는가?
         │
    ┌────┼──────────────┐
  전체   웹 레이어만    DB/Service만
  흐름                  (웹 제외)
    │         │              │
RANDOM_PORT  MOCK           NONE
(실제 HTTP)  (MockMvc)   (Bean 주입만)
```

---

## 어노테이션 선택 기준표

| 테스트 목적 | 권장 어노테이션 | 특징 |
|-----------|--------------|------|
| API 전체 흐름 (실제 HTTP) | `@SpringBootTest(RANDOM_PORT)` | 가장 무겁지만 실제에 가깝다 |
| Controller 레이어만 | `@WebMvcTest` | MockMvc 자동 설정, 가볍다 |
| JPA Repository만 | `@DataJpaTest` | 인메모리 DB, 가볍다 |
| Service 비즈니스 로직 | `@SpringBootTest(NONE)` 또는 순수 단위 테스트 | — |

---

## 실전 체크리스트

✨ **`@Autowired`가 null인가?**

`@SpringBootTest`가 없으면 Spring 컨테이너가 뜨지 않는다. 테스트 클래스에 붙인다

<br/>

✨ **테스트가 너무 느린가?**

`@SpringBootTest`는 전체 컨텍스트를 로딩한다

`@WebMvcTest`, `@DataJpaTest` 같은 슬라이스 테스트로 범위를 줄인다

<br/>

✨ **실제 HTTP 통신을 테스트하고 싶은가?**

`webEnvironment = RANDOM_PORT`와 `TestRestTemplate`을 함께 사용한다

<br/>

✨ **MockMvc로 컨트롤러를 테스트하려는가?**

`webEnvironment = MOCK` (기본값)이면 된다
