> @Autowired는 Spring 컨테이너가 있어야 동작한다  
> ==@SpringBootTest가 없으면 컨테이너 자체가 뜨지 않기 때문에 주입할 대상이 없다==

---

## @Autowired는 무엇인가?

Spring 컨테이너에 등록된 Bean을 주입받는 어노테이션이다

```java
@Autowired
private MemberRepository memberRepository;
```

Spring이 이 필드를 보고 "컨테이너에서 MemberRepository 타입 Bean을 꺼내서 넣어준다"

---

## 왜 @SpringBootTest가 없으면 동작하지 않는가?

- ✨ **일반 JUnit 테스트는 Spring 컨테이너를 띄우지 않는다**

```java
class MemberServiceTest {
    @Autowired  // ❌ 컨테이너가 없으니 주입할 주체가 없다 → null
    private MemberService memberService;
}
```

JUnit이 테스트 클래스를 인스턴스화할 때는 그냥 `new MemberServiceTest()`를 한다

Spring이 개입하지 않기 때문에 `@Autowired`는 무시되고 필드는 `null`이 된다

<br/>

- ✨ **@SpringBootTest를 붙이면 Spring 컨테이너가 먼저 뜬다**

```java
@SpringBootTest
class MemberServiceTest {
    @Autowired  // ✅ 컨테이너가 Bean을 주입해준다
    private MemberService memberService;
}
```

`@SpringBootTest`가 Spring의 테스트 컨텍스트를 로딩하고,  
그 후에 JUnit이 테스트를 실행한다

---

## 정리

```
@SpringBootTest 없음:
JUnit → new MemberServiceTest() → @Autowired 무시 → null

@SpringBootTest 있음:
Spring 컨테이너 시작 → Bean 등록 → JUnit → 테스트 실행 → @Autowired 주입
```

---

## 핵심

`@Autowired`는 Spring의 기능이다

Spring이 없는 환경에서 Spring의 기능을 쓰려 하면 동작하지 않는다

`@SpringBootTest`는 테스트 환경에 Spring 컨테이너를 올려주는 어노테이션이다
