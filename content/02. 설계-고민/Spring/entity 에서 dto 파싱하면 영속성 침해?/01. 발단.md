Entity에 `toDto()` 메서드를 만들어서 DTO로 변환하는 코드를 작성했다

```java
@Entity
public class Reservation {

    public ReservationResponse toDto() {
        return new ReservationResponse(id, name, date);
    }
}
```

그런데 Entity가 DTO를 직접 알고 있는 게 맞는지 의문이 들었다

DTO는 응답 형태에 맞게 계속 바뀔 수 있는데, 그 변화가 Entity까지 영향을 준다는 게 이상하게 느껴졌다
