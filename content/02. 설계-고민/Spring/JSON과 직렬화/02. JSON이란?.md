## 정의

JSON — JavaScript Object Notation

데이터를 교환하기 위한 텍스트 형식이다

JavaScript에서 출발했지만, 지금은 거의 모든 언어에서 표준적으로 쓰인다

---

## 왜 필요한가?

서버(Java)와 클라이언트(JavaScript)는 서로 다른 언어로 만들어져 있다

서로가 이해할 수 있는 공통 형식이 없으면 데이터를 주고받을 수 없다

JSON이 그 공통 언어 역할을 한다

---

## 생김새

```json
{
  "name": "한다",
  "age": 25,
  "languages": ["Java", "Python"],
  "address": {
    "city": "서울",
    "district": "강남구"
  }
}
```

- [I] `{ }` 중괄호 — 객체
- [I] `[ ]` 대괄호 — 배열
- [I] `"key": value` 형식으로 데이터를 표현한다
- [I] 값은 문자열, 숫자, 불리언, 배열, 객체, null이 올 수 있다

---

## Spring Boot와 JSON

`@RestController`를 쓰면 Java 객체가 자동으로 JSON으로 변환되어 응답된다

```java
@GetMapping("/user")
public User getUser() {
    return new User("한다", 25);  // Java 객체를 반환
}
```

실제 응답:

```json
{
  "name": "한다",
  "age": 25
}
```

이 변환을 담당하는 것이 `Jackson` 라이브러리다

`spring-boot-starter-web`에 기본으로 포함되어 있다

## 핵심

JSON을 자연스럽게 읽고 쓸 수 있어야 API 개발과 디버깅이 편해진다
