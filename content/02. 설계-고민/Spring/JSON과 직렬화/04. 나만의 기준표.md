
> 직렬화는 언어 밖으로 내보내기, 역직렬화는 언어 안으로 가져오기다  
> ==Jackson이 자동으로 해주지만, 안 될 때를 위해 원리를 알아야 한다==

---

## 흐름 정리

```
클라이언트 → 서버: JSON 문자열 → @RequestBody → 역직렬화 → Java 객체
서버 → 클라이언트: Java 객체 → 직렬화 → JSON 문자열 → 응답
```

---

## 자주 만나는 문제 기준표

| 증상 | 원인 | 해결 |
|------|------|------|
| 응답 JSON에 필드가 없다 | 필드가 `private`이고 getter 없음 | getter 추가 또는 `@JsonProperty` |
| 요청 JSON 파싱 실패 | JSON 키와 필드명 불일치 | `@JsonProperty("json_key")` |
| 특정 필드를 JSON에서 숨기고 싶다 | — | `@JsonIgnore` |
| null 필드를 JSON에 포함하지 않으려면 | — | `@JsonInclude(NON_NULL)` |

---

## 실전 체크리스트

- [I] **`@RequestBody`로 받은 객체의 필드가 null인가?**

JSON 키 이름과 Java 필드 이름이 일치하는지 확인한다

<br/>

- [I] **응답 JSON에 원하는 필드가 없는가?**

Jackson은 기본적으로 public getter를 기준으로 직렬화한다

getter가 없거나 접근 제어자가 막혀있지 않은지 확인한다

<br/>

- [I] **Jackson이 역직렬화할 때 "No suitable constructor found" 오류?**

기본 생성자(no-arg constructor)가 필요하다

`@NoArgsConstructor` 또는 `@JsonCreator`를 사용한다
