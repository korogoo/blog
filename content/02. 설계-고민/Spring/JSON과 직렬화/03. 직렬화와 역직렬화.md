> ==객체를 전송 가능한 형태로 변환하는 것이 직렬화, 다시 객체로 복원하는 것이 역직렬화다==

---

## 직렬화 (Serialization)

Java 객체 → 전송 가능한 형태(JSON, bytes 등)로 변환하는 것

```
User 객체  →  JSON 문자열
new User("한다", 25)  →  {"name":"한다","age":25}
```

메모리 안의 객체는 그 자체로 네트워크로 보내거나 파일에 저장할 수 없다

복잡한 구조를 한 줄의 데이터로 펼쳐주는 것이다

---

## 역직렬화 (Deserialization)

전송받은 형태(JSON, bytes 등) → Java 객체로 복원하는 것

```
JSON 문자열  →  User 객체
{"name":"한다","age":25}  →  new User("한다", 25)
```

---

## 왜 필요한가?

네트워크는 바이트 스트림만 이해한다

객체, 클래스 같은 개념은 프로그래밍 언어 안에서만 존재한다

| 상황 | 필요한 변환 |
|------|-----------|
| 서버 → 클라이언트 응답 | 직렬화 (객체 → JSON) |
| 클라이언트 → 서버 요청 | 역직렬화 (JSON → 객체) |
| 객체를 파일에 저장 | 직렬화 |
| Redis 캐시에 저장 후 꺼내기 | 직렬화 → 역직렬화 |

---

## Spring Boot에서

Jackson이 자동으로 처리해준다

```java
// 직렬화: User 객체 → JSON 응답
@GetMapping("/user")
public User getUser() {
    return new User("한다", 25);
}

// 역직렬화: JSON 요청 → User 객체
@PostMapping("/user")
public void createUser(@RequestBody User user) {
    // user 객체로 바로 쓸 수 있다
}
```

`@RequestBody`가 역직렬화를 담당하고  
`@RestController`가 직렬화를 담당한다

---

## 핵심

직렬화는 "언어 밖으로 내보내기", 역직렬화는 "언어 안으로 가져오기"다

네트워크 통신, 파일 저장, 캐시 모두 이 변환 과정이 수반된다
