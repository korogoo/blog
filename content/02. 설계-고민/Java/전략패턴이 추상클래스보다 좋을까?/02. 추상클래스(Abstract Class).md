> 추상 클래스는 ==공통 상태와 공통 로직을 상속으로 공유하는 방법==이다

---

## 개념

```java
public abstract class AbstractMovePiece {

    private final MoveDirection direction; // 공통 상태

    protected AbstractMovePiece(MoveDirection direction) {
        this.direction = direction;
    }

    // 공통 로직 — 자식 클래스가 그대로 사용
    protected List<Position> getPath(Position from) {
        return direction.getPositionsFrom(from);
    }

    // 추상 메서드 — 자식 클래스가 반드시 구현
    public abstract List<Position> getMovablePositions(Position from, Board board);
}

public class Chariot extends AbstractMovePiece {
    public Chariot() {
        super(MoveDirection.STRAIGHT); // 공통 상태 주입
    }

    @Override
    public List<Position> getMovablePositions(Position from, Board board) {
        return getPath(from).stream()
            .takeWhile(pos -> board.isEmpty(pos))
            .collect(toList());
    }
}
```

---

## 장점

✨ **공통 상태를 자연스럽게 공유한다**

필드, 생성자, 공통 메서드를 한 곳에 둔다

<br/>

✨ **코드 중복을 줄인다**

자식 클래스가 부모의 메서드를 그대로 사용한다

<br/>

✨ **`protected`로 내부만 공유할 수 있다**

외부에 노출하지 않으면서 자식 클래스와 공유한다

---

## 단점

✨ **상속 구조에 묶인다**

`extends`는 하나만 가능하다. 다른 클래스를 추가로 상속할 수 없다

<br/>

✨ **부모-자식 결합도가 높다**

부모 클래스 변경이 모든 자식 클래스에 영향을 준다

<br/>

✨ **마와 상처럼 거의 같은 경우 코드 중복 문제**

이동 방식이 거의 동일한데 별도 클래스로 관리하면 오히려 중복이 생긴다

→ **해결**: 상수값(이동 방향 등)을 생성자로 주입해 단일 클래스에서 처리
