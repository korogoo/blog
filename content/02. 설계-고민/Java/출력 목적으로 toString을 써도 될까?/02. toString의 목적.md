## toString()이란?

모든 Java 객체는 `Object.toString()`을 상속받는다

기본 구현은 `클래스명@해시코드`를 반환한다

개발자가 오버라이드해서 객체의 상태를 사람이 읽을 수 있는 형태로 반환한다

---

## 어떤 용도로 쓰이는가

- [I] **디버깅**

IDE의 디버거, 스택 트레이스에서 객체 상태를 볼 때 사용

<br/>

- [I] **로깅**

`logger.debug("현재 상태: {}", object)` — 내부적으로 `toString()` 호출

<br/>

- [I] **테스트 실패 메시지**

AssertJ가 테스트 실패 시 객체를 표현할 때 `toString()` 호출

---

## 올바른 toString() 구현

```java
public class Position {
    private final int row;
    private final int column;

    @Override
    public String toString() {
        return "Position{row=" + row + ", column=" + column + "}";
        // 디버깅 용도 — 정보를 표현하는 형식
    }
}
```

---

## 로깅 라이브러리가 toString()을 자동 호출한다

```java
// SLF4J, Logback 등
logger.info("기물 상태: {}", piece); // ← piece.toString()이 호출됨
```

`toString()`에 출력 로직이 있으면 로깅할 때도 그 포맷으로 출력된다

의도치 않은 포맷이 로그에 남을 수 있다

---

## 결론

> `toString()`은 **개발자가 객체를 이해하기 위한** 메서드다
>
> 사용자에게 보여주는 **표현 목적**의 메서드는 따로 만든다
