
> 사용자에게 보여줄 표현은 ==도메인 객체가 아닌 뷰 레이어에서 만든다==

---

## 문제

```java
// ❌ — toString()을 출력에 직접 사용
public void printBoard(Board board) {
    for (int row = 1; row <= 10; row++) {
        for (int col = 1; col <= 9; col++) {
            Piece piece = board.getPieceAt(new Position(row, col));
            System.out.print(piece.toString()); // 출력 포맷이 toString에 종속
        }
        System.out.println();
    }
}
```

나중에 출력 포맷이 바뀌면 `Piece.toString()`을 수정해야 한다

로깅에서도 같은 포맷이 나온다 — 디버그용 로그가 사용자 포맷으로 나온다

---

## 해결 1: 별도 표현 메서드

```java
// ✅ — 표현 책임을 별도 메서드로
public class Piece {

    @Override
    public String toString() {
        return "Piece{type=" + type + ", side=" + side + "}"; // 디버깅용
    }

    public String display() {
        return side.getSymbol() + type.getSymbol(); // 출력용 (예: "한차")
    }
}
```

---

## 해결 2: 뷰 레이어에서 렌더링

```java
// ✅ — 렌더링 책임을 뷰 클래스로 분리
public class BoardRenderer {

    public String render(Board board) {
        StringBuilder sb = new StringBuilder();
        for (int row = 10; row >= 1; row--) {
            for (int col = 1; col <= 9; col++) {
                sb.append(renderPiece(board.getPieceAt(Position.of(row, col))));
            }
            sb.append("\n");
        }
        return sb.toString();
    }

    private String renderPiece(Piece piece) {
        if (piece == null) return ".";
        return piece.getDisplaySymbol(); // 도메인에서 표현 값만 제공
    }
}
```

## 디버깅을 위한 toString() 활용

```java
public class Piece {

    @Override
    public String toString() {
        return String.format("Piece[%s, %s]", type, side);
    }
}

// IDE 디버거에서 Piece 객체를 보면 "Piece[CANNON, HAN]" 으로 표시
// logger.debug("piece={}", piece) → "piece=Piece[CANNON, HAN]" 으로 로그
```

디버깅, 로깅에서는 의도한 대로 상태가 보인다

## 요약

| 목적 | 방법 |
|---|---|
| 디버깅/로깅 | `toString()` 오버라이드 |
| 사용자 출력/화면 렌더링 | `display()`, `getSymbol()`, 별도 Renderer |
| 테스트 실패 메시지 | `toString()` (자동 사용) |
