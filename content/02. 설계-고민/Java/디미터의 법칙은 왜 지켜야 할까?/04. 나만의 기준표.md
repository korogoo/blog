> "이 코드가 디미터 위반인가?" 에 대한 내 답

---

## 핵심 질문

> "한 줄에서 탐색하는 객체가 몇 단계인가?"

 - [p] 1단계: `board.move()` 
- [!] 2단계: `board.getPiece(pos).getScore()` 
- [c] 3단계 이상: `a.getB().getC().doSomething()`

---

## 판단 기준표

- [p] 인스턴스 변수의 메서드 `this.field.method()`
- [p] 파라미터의 메서드 `param.method()`
- [p] 직접 생성 객체 `new Object().method()`
- [p] 같은 타입 체이닝 `stream().filter().map()...`
- [p] 빌더 체이닝 `builder.set().set().build()`
- [!] B 내부에 의존 `a.getB().method()`
- [c] 기차 충돌 `a.getB().getC().method()`

---

## 해결 전략

- [I] **중간 객체에 메서드를 위임한다**

`a.getB().doSomething()` → `a.doSomethingViaB()`

<br/>

- [I] **일급 컬렉션에 로직을 옮긴다**

`list.stream().filter(...).count()` → `pieces.countBySide(side)`
   
<br/>

- [I] **Tell, Don't Ask**

값을 꺼내서 판단하지 말고, 객체에게 판단을 시킨다

---

## 실전 체크리스트

- [I] **한 표현식에 점이 2개 이상인가?**

탐색인지 체이닝인지 구분한다

<br/>

- [I] **getter로 꺼낸 값으로 다시 getter를 호출하는가?**

중간 객체에 메서드를 추가해 위임한다

<br/>

- [I] **`stream()`을 외부로 반환하는가?**

컬렉션 내부에서 처리하고 결과만 반환한다 (→ [[02. 일급 컬렉션이란?]])
