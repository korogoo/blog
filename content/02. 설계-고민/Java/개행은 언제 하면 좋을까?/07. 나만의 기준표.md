## 상황별 기준표

### 클래스 레벨

- [p] 상수 필드 <-사이-> 인트선트 필드
- [p] 필드 <-사이-> 생성자
- [p] 생성자 <-사이-> 메서드
- [p] 메서드 <-사이-> 메서드

- [c] 필드 하나씩
- [c] 메서드 첫 줄
- [c] 메서드 마지막 줄

### 메서드 내부

- [p] 검증 블록 <-사이-> 처리 시작
- [p] 처리 단계 내 관심사 전환

- [c] 짧은 메서드 (3줄 이하)
- [c] return 직전 (단순 반환)
- [c] 모든 문장 사이
