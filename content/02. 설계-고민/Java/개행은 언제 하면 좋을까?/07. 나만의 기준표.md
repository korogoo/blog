## 상황별 기준표

### 클래스 레벨

👍 상수 필드 <-사이-> 인트선트 필드
👍 필드 <-사이-> 생성자
👍 생성자 <-사이-> 메서드
👍 메서드 <-사이-> 메서드

👎 필드 하나씩
👎 메서드 첫 줄
👎 메서드 마지막 줄

### 메서드 내부

👍 검증 블록 <-사이-> 처리 시작
👍 처리 단계 내 관심사 전환

👎 짧은 메서드 (3줄 이하)
👎 return 직전 (단순 반환)
👎 모든 문장 사이

### 테스트 코드

👍 given <-사이-> when <-사이-> then
👍 given 내부 준비 대상이 다를 때
👍 //given, //when, //then 주석 전
