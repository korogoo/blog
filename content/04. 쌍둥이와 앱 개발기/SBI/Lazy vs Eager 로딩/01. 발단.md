바리바리 피드 화면에서 코스 목록을 뿌려야 했다

각 코스 카드에는 제목, 대표 이미지, 핀 개수(경유지 수)가 필요하다  
그래서 `courseJpaRepository.findAll()`로 전체 코스를 가져온 뒤 각 코스마다  `course.getPins().size()`를 호출했다

근데 쿼리가 코스 수 + 1번씩 나가고 있었다

```sql
Hibernate: select c1_0.id,c1_0.title,c1_0.thumbnail_url from course c1_0
Hibernate: select p1_0.course_id,p1_0.id,p1_0.name from pin p1_0 where p1_0.course_id=?
Hibernate: select p1_0.course_id,p1_0.id,p1_0.name from pin p1_0 where p1_0.course_id=?
Hibernate: select p1_0.course_id,p1_0.id,p1_0.name from pin p1_0 where p1_0.course_id=?
```

<br/>

찾아보니 `CourseEntity` 의 `List<PinEntity>` 는 Collection 이기 때문에 기본으로 fetch 타입이 LAZY 로 설정이 된다고 한다  

이 LAZY 설정 때문에 size 가 호출될 때 쿼리가 나가는 것을 깨닫고,  
그러면 EAGER로 바꿔야겠다 하고 `CourseJpaEntity`의 `@OneToMany`에 `fetch = FetchType.EAGER`를 추가했다

근데 SQL 로그를 보니 코스 수만큼 또 쿼리가 나갔다

❓ 왜 EAGER로 바꿨는데 N+1 문제가 발생하는거지?
